Everything here is provided **as-is**. In practice, that means:

- ✅ **It will likely work.** We build and use these tools ourselves, and we put in a good-faith, best-effort attempt to make them solid.
- ⚠️ **It's not guaranteed.** Your environment, data, versions, and setup may differ from ours, and things can break in ways we haven't seen.
- 🕐 **Support is best-effort.** Issue are fixed at the contributors convenience, and we can't promise timelines.
- 🔧 **Updates aren't promised.** Tools may change, be replaced, or be retired without notice.
- 🧪 **Test before you trust.** Please try tools in a safe environment first, and always keep backups before running anything that changes data or systems.
- 🙋 **You're in charge of how you use it.** You are responsible for reviewing the feature set and deciding whether it's right for your situation.

We're sharing these tools because we like being helpful, not because we're offering a product or a service.

## 📊 Usage statistics

We believe in being upfront about this: **our tools may collect basic usage statistics and you will be asked for consent before any data is collected.** We use them to understand which tools are actually being used, where, and how often, so we can decide what to maintain, improve, or retire.

### What we collect

For each run of a tool, we record:

- **The targeted environment**, meaning the system or environment the tool was run against
- **The user name** of the person running the tool
- **The domain** the user belongs to
- **Usage information** about the tool itself (for example, which tool was run and when)

### What we never collect

- 🔒 **The actual data processed by the tools.** We don't see, copy, or store the content, records, files, or results that a tool works on. Statistics describe _that_ a tool was used, never _what it was used on_.

### Why we collect it

- To see which tools are useful and which are not
- To prioritize our limited maintenance time
- To understand the environments our tools are used in

### Good to know

- Usernames and domains can count as personal data in many jurisdictions. Please make sure that running these tools, and the statistics collection that comes with them, is appropriate for your organization and complies with your own policies and local regulations.
- Statistics are used for the purposes described above and are not sold or shared for advertising.
- Usage data is collected as a condition of use. Tools that collect usage data are licensed under the Omada Free Tool Licence. You can object or request deletion at [Omada privacy](mailto:privacy@omada.net); you may then no longer use the tool. For more information, see our Privacy Policy: [Privacy Policy](https://omadaidentity.com/company/privacy-policy)
